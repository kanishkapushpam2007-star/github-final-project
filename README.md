# GitHub Final Project

## Project Name
Simple Interest Calculator

## Project Overview
This project is a Bash script that calculates simple interest based on the principal amount, annual interest rate, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Features
- Takes the principal amount as input.
- Takes the annual interest rate as input.
- Takes the time period in years as input.
- Calculates and displays simple interest.

## Usage Instructions
1. Open a terminal.
2. Run the simple-interest.sh script.
3. Enter the principal amount.
4. Enter the interest rate.
5. Enter the time period.
6. View the simple interest result.

## Example Input
Principal: 1000
Rate: 5
Time: 2 years

## Example Output
Simple Interest: 100

## Technologies Used
Bash scripting and GitHub.

## Purpose
This project demonstrates basic shell scripting and mathematical calculations.
